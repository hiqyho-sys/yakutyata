# Якутята — из холода в любовь

Сайт волонтёрской команды «Якутята»: история спасения собак, информация о команде и Анне, география помощи, реквизиты и каталог из 44 карточек с фотогалереями.

Выбранный дизайн: северное сияние, закреплённая история со сменой фотографий при прокрутке и интерактивный глобус. Режим «Без анимации» доступен посетителям.

## Публикация

Готовая статическая версия. Сборка и сервер не требуются.

В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.

Главная страница — `index.html`. Все фотографии каталога находятся в `catalog/`; сохраняйте эту папку рядом с главной страницей.

## Обновление

Измените `index.html` или изображения в `catalog/`, затем сохраните изменения в ветку `main`. GitHub Pages опубликует обновление автоматически.

Сведения о собаках взяты из предоставленного каталога. Данные об актуальности пристройства следует уточнять у куратора команды. Статистика предоставлена командой 3 октября 2026 года.

Сайт создан с помощью OpenAI Codex. Сведения о команде и исходные фотографии предоставлены заказчиком.
